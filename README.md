# 右键菜单管家

Windows 本地桌面工具。双击 **右键菜单管家.exe** 即可使用，无需安装第三方依赖，不联网、不自动修改菜单。

## 使用

1. 启动后自动扫描，默认显示桌面、文件夹、文件和磁盘等常见场景。
2. 搜索菜单名称或软件名称，或在场景下拉框中选择“文件夹上右键”等位置。这与文件夹内空白处右键不同；文件夹筛选同时包含适用的经典菜单和 Windows 11 菜单。     
   勾选 **隐藏 Windows 默认项** 可隐藏已识别的系统菜单；来源待确认的项目仍保留，避免漏掉第三方软件。取消该开关即可查看全部；“来源待确认”筛选可单独查看无法确定的来源。筛选本身不会修改菜单或改变已有选择。
3. **勾选表示保留，取消勾选表示禁用**。选择在切换筛选时会保留。
4. 点击“应用选择”，确认具体修改列表。每个禁用项目会先完整备份，再移除该菜单注册项。
5. 恢复时，选择“已禁用”筛选，重新勾选项目并应用。备份恢复会校验内容，不覆盖软件重新创建的入口。

灰色项目可能需要管理员权限，或只能检测。编辑所有用户的菜单，请点“以管理员重新打开”，接受 Windows 授权后重新选择项目。打开文件/文件夹、默认操作和应用包菜单在本版中只检测。

同一注册路径同时出现在“当前用户”和“所有用户”时，选择会同步两份来源，避免删除一份后 Windows 又转用另一份。同一个软件在不同场景中的入口仍可分别选择。

如果应用修改后右键菜单仍显示，点击“重启资源管理器”。此按钮会再次确认：桌面和任务栏短暂消失、打开的文件夹窗口关闭，因此应先结束复制或移动任务。工具不会自动重启资源管理器。

## 检测范围与限制

| 类型                                         | 检测            | 修改              |
| ------------------------------------------ | ------------- | --------------- |
| 桌面、文件夹空白处、文件夹、磁盘、所有文件、库的普通菜单               | 支持            | 支持备份、禁用、恢复      |
| 文件扩展名、关联 ProgID、SystemFileAssociations 的菜单 | 支持            | 默认操作只检测，其他菜单可管理 |
| Shell 的 ContextMenuHandlers 扩展             | 支持，并显示模块和软件来源 | 按注册场景禁用、恢复整个扩展  |
| Windows 11 应用包中的 fileExplorerContextMenus  | 支持列出清单来源      | 本版仅检测           |
| Windows 内置菜单、动态生成按钮、特定对象或 Shift 条件下显示的内容   | 无法完整还原实际菜单    | 不宣称能够全部管理       |

扫描的是 **64 位资源管理器的注册来源**，数量不是当前右键实际显示的按钮数量。用户选择的文件、应用逻辑、Shift 键、同一扩展生成多个按钮等都影响最终菜单。32 位应用自己的右键菜单不在本版范围内。

软件名称根据模块的产品名称和公司信息推测，不等于数字签名验证。百度网盘、夸克网盘、Bandizip 等内部名称会转为易识别的名称，支持中文搜索。选中项目默认显示操作说明；勾选“高级详情”才显示注册路径和模块。软件识别仍属于推测。

“来源分类（推测）”列区分 **Windows 默认项 / 第三方软件 / 来源待确认**。分类结合 Windows 系统目录、模块公司信息和部分内置应用包名称；Visual Studio、OneDrive 等微软独立应用不因此归入 Windows 默认项，系统目录内的 NVIDIA 模块也仍属于第三方。Windows 启动器调用外部软件时，会检查命令中的外部载荷。分类不是对每个 Windows 版本预装清单的权威认定，不确定的来源不会直接归为系统默认项。

工具不改变默认文件关联、不卸载软件、不加载第三方扩展 DLL 执行检测。软件更新后可能重新注册菜单；再次扫描会提示已管理项目重新出现，不会后台自动删除。

## 备份

默认目录：`%LOCALAPPDATA%\RightMenuKeeper\Backups`。点击“打开备份”可查看。

备份保存注册项的字符串、环境变量字符串、二进制、多字符串、DWORD/QWORD 和子项，并记录操作状态。先落盘并校验，再执行禁用；应用前也会核对扫描时的指纹，防止使用过期扫描内容。

备份与当前 Windows 用户绑定，请保留备份目录。只使用本工具生成的备份。本版不会复制注册项 ACL，恢复项采用父项的权限继承。

## 编译与验证

源码：`RightMenuKeeper.cs`；运行 `build.ps1`，使用 Windows 自带 .NET Framework 编译器生成 x64 EXE。

验证命令：

```powershell
.\右键菜单管家.exe --scan "菜单扫描.json"
.\右键菜单管家.exe --self-test "测试结果.json"
```

自测使用独立测试注册项，不修改现有菜单；覆盖完整值类型往返、备份禁用恢复、恢复冲突、过期扫描和界面选择逻辑。若从脚本中等待 EXE 完成，可使用 `Start-Process -Wait`。

## 本机验证

2026-10-09：扫描到 1,185 个注册来源，常见场景 93 个，读取错误 0 条。组成：普通菜单 838、Shell 扩展 160、应用包菜单 187。验证报告为 `test-results.json`，只读扫描结果为 `current-menu-scan.json`。

机制依据：[微软 Shell 扩展注册说明](https://learn.microsoft.com/en-us/windows/win32/shell/handlers)、[Windows 11 应用包菜单说明](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/integrate-packaged-app-with-file-explorer)。

百度网盘等扩展可能一次生成多个按钮，本工具按入口管理整个按钮组，不支持逐个开关其中的动态按钮。说明中的“可能包含”是帮助识别的软件功能示例，不表示扫描出了每一个按钮。Windows 11 应用包菜单会明确标记为仅检测，禁用经典入口不会保证它也消失。
